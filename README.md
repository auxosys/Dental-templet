13. FRAME PRELOADING

==================================================

The sequence is approximately 15 FPS.

Do NOT block initial page rendering while loading every frame.

Immediately prioritize the first 30–50 frames.

Then progressively preload/decode the remaining frames.

Use Image.decode() where supported.

Use an efficient frame cache.

Do not recreate Image objects on every scroll event.

Do not create hundreds of DOM image elements.

The first frame should appear quickly.

Do not make the canvas excessively large on high-DPI screens.
